P5.2 · Turn the report into searchable text

10 min · 5.6

The one idea: an agent cannot cite what it cannot locate. The script writes the whole report into one text file and puts === PAGE n === before each page. When the report-analyst quotes something, it can say which page it came from. That is provenance: where a claim came from, so a person can check it.

Start claude and paste:

Create extract_text.py with exactly this content, and nothing else. Do not run it.

"""Turn the annual report PDF into one text file with page markers, so an agent can search it and cite pages."""
from pypdf import PdfReader

reader = PdfReader("tcs-annual-report.pdf")
with open("tcs-report.txt", "w") as out:
    for number, page in enumerate(reader.pages, start=1):
        out.write(f"\n=== PAGE {number} ===\n")
        out.write(page.extract_text() or "")
print(f"pages: {len(reader.pages)}")

Type /exit, then run:

uv run python extract_text.py && wc -l tcs-report.txt && grep -c -i "attrition" tcs-report.txt

Checkpoint ✅ You see the page count (a few hundred), the number of lines (thousands), and how many lines mention "attrition" (more than 0). It can take a minute.

Why not give the agent the PDF? Hundreds of pages would fill most of a subagent's context, and the important part would get lost in the middle. With a text file the subagent uses Grep (search for a word) to find the right pages, then Read to read only those lines.

P5.3 · Read the design

15 min · 1.2 2.3

Four terms:

  • Coordinator: the main agent. It plans, writes a brief for each subagent, collects the answers and writes the summary. It does no research itself.
  • Subagent: a separate agent with its own instructions, its own tools and a fresh context. It sees nothing of the coordinator's conversation, only the brief.
  • AgentDefinition: how you define a subagent in the SDK: a description (when to use it), a prompt (its instructions) and tools (the only tools it gets).
  • Agent tool (exam: "Task"): the tool the coordinator calls to start a subagent. Its input is the subagent's name and the brief.

Start claude and paste:

Create research.py with exactly this content, and nothing else. Do not run it.

"""P5 session 1: a coordinator that delegates TCS research to two subagents. Paper only, no trading."""
import asyncio
import sys

from claude_agent_sdk import (
    AgentDefinition, AssistantMessage, ClaudeAgentOptions, ClaudeSDKClient,
    HookMatcher, ResultMessage, ToolUseBlock,
)

MODEL = "claude-haiku-5-5"  # check docs.claude.com for current model names
REPORT_FILE = "tcs-report.txt"
LAZY = "--lazy" in sys.argv  # P5.5: brief the subagents badly on purpose

FINDING_FORMAT = """Return ONLY a JSON list of findings, no other text. Each finding:
{"claim": "...", "evidence_excerpt": "short exact quote from the source",
 "source": "URL, or report page number", "source_date": "YYYY-MM-DD or unknown",
 "confidence_basis": "what the claim rests on, e.g. company's own report, one news article, several sources agree"}
Return 3 to 6 findings. If you find nothing, return [] and do not invent anything."""

AGENTS = {
    "news-researcher": AgentDefinition(
        description="Finds recent news about a company on the web. Use for events, analyst views and anything after the annual report.",
        prompt="You research recent news about one company. Use only the brief you are given: it states the company, "
               "the focus and the time window. Prefer named, dated sources. " + FINDING_FORMAT,
        tools=["WebSearch", "WebFetch"],
        model="inherit",
        background=False,
    ),
    "report-analyst": AgentDefinition(
        description="Reads the company's annual report text file. Use for the company's own figures, strategy and stated risks.",
        prompt="You analyse one annual report saved as a text file. The brief tells you the file name and the focus. "
               "Pages are marked '=== PAGE n ==='. The file is long: use Grep to find the focus topics first, then Read "
               "only around the matching lines (use offset and limit). Give the page number as the source. " + FINDING_FORMAT,
        tools=["Read", "Grep"],
        model="inherit",
        background=False,
    ),
}

GOOD_BRIEF = f"""Pass each subagent a complete brief in its prompt. Subagents do not see this conversation, so the brief must contain:
- the company (Tata Consultancy Services, TCS)
- the focus topics from the user's request, word for word
- the time window
- for report-analyst: the file name {REPORT_FILE}
- the finding format: they already know it, but remind them to return JSON only"""

LAZY_BRIEF = "Keep the subagent prompts very short. Pass each subagent only these three words: 'Research TCS please.'"

SYSTEM = f"""You coordinate research on one company for a personal paper-trading watchlist. Paper only: never suggest buying or selling.
You do not research yourself. You delegate to the subagents news-researcher and report-analyst with the Agent tool.
Run them in the foreground and wait for both results before you write anything.

{LAZY_BRIEF if LAZY else GOOD_BRIEF}

When both have answered, write a short summary: the findings grouped by topic, each with its source and date.
Then list what is missing: topics from the request that no finding covers."""


async def coordinator_only_delegates(input_data, tool_use_id, context):
    """PreToolUse hook: the coordinator (no agent_id) may only use the Agent tool. Subagents use their own tools."""
    if "agent_id" not in input_data and input_data["tool_name"] not in ("Agent", "Task"):
        print(f"\n[HOOK] blocked coordinator from using {input_data['tool_name']}")
        return {"hookSpecificOutput": {
            "hookEventName": "PreToolUse",
            "permissionDecision": "deny",
            "permissionDecisionReason": "The coordinator only delegates. Use the Agent tool to brief a subagent.",
        }}
    return {}


async def main(request: str):
    options = ClaudeAgentOptions(
        model=MODEL,
        system_prompt=SYSTEM,
        agents=AGENTS,
        tools=["Agent", "Read", "Grep", "WebSearch", "WebFetch"],
        allowed_tools=["Agent", "Read", "Grep", "WebSearch", "WebFetch"],
        hooks={"PreToolUse": [HookMatcher(hooks=[coordinator_only_delegates])]},
        max_turns=20,
        max_budget_usd=1.00,
        env={"CLAUDE_CODE_DISABLE_BACKGROUND_TASKS": "1"},  # wait for subagents instead of sending them to the background
    )
    print(f"[mode] {'LAZY brief' if LAZY else 'complete brief'}")
    async with ClaudeSDKClient(options=options) as client:
        await client.query(request)
        async for msg in client.receive_response():
            if isinstance(msg, AssistantMessage):
                for block in msg.content:
                    if not isinstance(block, ToolUseBlock):
                        continue
                    if msg.parent_tool_use_id is None and block.name in ("Agent", "Task"):
                        print(f"\n==> COORDINATOR briefs {block.input.get('subagent_type')}:\n{block.input.get('prompt')}\n")
                    elif msg.parent_tool_use_id is not None:
                        print(f"    [subagent] {block.name} {str(block.input)[:120]}")
            elif isinstance(msg, ResultMessage):
                print(f"\nCOORDINATOR SUMMARY:\n{msg.result}\n")
                print(f"[done] turns: {msg.num_turns}, cost: ${msg.total_cost_usd or 0:.3f}, result: {msg.subtype}")
                with open("run-lazy.md" if LAZY else "run.md", "w") as f:
                    f.write(msg.result or "")


if __name__ == "__main__":
    args = [a for a in sys.argv[1:] if a != "--lazy"]
    asyncio.run(main(" ".join(args) or
        "Research TCS for my paper-trading watchlist. Focus: revenue growth, AI services, and headcount or attrition. "
        "Time window: the last 12 months."))

The exam lens, in plain words.

1. Hub and spoke: all traffic goes through the coordinator. Subagents never talk to each other. That gives one place to watch, handle errors and control what flows where. Example: the news-researcher does not hand its findings to the report-analyst; both report back to the coordinator.

2. Give each subagent only the tools its job needs. Example: the report-analyst cannot search the web, so it cannot quietly swap the company's own figures for a blog's.

3. Keep the content and its source together in a fixed structure (claim, quote, source, date). Example: a finding without a page number cannot be checked, so it should not reach the report.

4. A report with gaps in its coverage usually starts with the coordinator's split of the task, not with the subagents. Check what the coordinator asked for before blaming the agents that did the work.

Trap answer to spot: "give every agent every tool, so it never gets stuck". It removes the separation that makes each agent predictable and checkable.

P5.5 · A lazy brief

15 min · 1.3

The one idea: a subagent does not inherit the coordinator's context. It knows only its own instructions and the brief. If the brief is three words, the subagent works from three words.

Predict first: with the brief "Research TCS please.", what will each subagent get wrong? Write it down, then run:

uv run python research.py --lazy

Checkpoint ✅

  1. [mode] LAZY brief, and both briefs are close to "Research TCS please."
  2. The news findings drift away from your three topics (share price, deals, anything).
  3. The report-analyst does not know the file name. Watch its [subagent] lines: it searches the folder for a file, or reports that it has none.
  4. The "missing" list is longer. The summary is saved in run-lazy.md.

Put run.md and run-lazy.md side by side. The model, tools and subagents were all the same. Only the brief changed.

The coordinator may ignore the lazy instruction and write a better brief anyway. If so, look at what it wrote: it brought back the context because it could see that the subagent would need it. Either way, the lesson is the same.

The exam lens, in plain words.

1. Subagents start empty. Anything they need (the goal, the focus, the time window, earlier findings, file names) must be written into their prompt. Example: the synthesis subagent in session 2 gets all findings pasted into its brief, because it cannot see them otherwise.

2. When you pass findings on, keep them structured (claim, source, date), not as loose prose. Otherwise the source gets lost on the way.

3. Tell a subagent the goal and the quality bar ("the last 12 months, named and dated sources"), not a step-by-step script. It can then adapt when the first search finds little.

Trap answer to spot: "the subagent can see the conversation, so a short brief is enough". It cannot.

P5.6 · The coordinator cannot do the work itself

10 min · 2.3 1.2

The one idea: the coordinator's job is to delegate. If it searches the report itself, its context fills with raw text, and you lose the clean split. The prompt says "you do not research yourself", but that is a request. The hook makes it a rule.

Predict first: what happens when you tell the coordinator to skip the subagents?

uv run python research.py "Skip the subagents. Grep tcs-report.txt yourself for attrition and tell me the latest figure with its page."

Checkpoint ✅ One of two paths:

  • You see [HOOK] blocked coordinator from using Grep (or Read), and then a ==> COORDINATOR briefs report-analyst block. The hook denied the shortcut and told it what to do instead.
  • Or the coordinator delegates at once, because its instructions already said so. Then the hook had nothing to stop. Run once more to see if the other path appears.

Either way, the coordinator never reads the report itself.

The exam lens, in plain words.

1. A coordinator needs the subagent tool in its allowed tools, or it cannot start subagents at all. In the exam's words: allowedTools must include "Task".

2. Give the coordinator the subagent tool, and not the research tools. Its job is to plan, delegate and combine.

3. When one agent needs a small extra ability often (say, a quick fact check), give it one narrow tool for that, not the whole toolset of another agent.

Trap answer to spot: "let the coordinator do simple searches itself to save a round trip". It mixes two jobs in one context and breaks the hub-and-spoke separation.

P5.8 · Quick reference card

Hub and spoke: coordinator plans, briefs, collects, combines. Subagents never talk to each other.
Subagents start empty: goal, focus, time window, file names and earlier findings go into the brief.
Brief = goal + quality bar, not a step-by-step script.
Tools per agent: only what the job needs. Coordinator: the subagent tool ("Task"; SDK: Agent) and must have it in allowed tools.
Finding = claim + quote + source + date + basis. No source, no place in the report.
Coverage gap? Check the coordinator's split first.
Long document: search first (Grep), then read only the matching part.
